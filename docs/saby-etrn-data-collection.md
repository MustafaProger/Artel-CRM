# Сбор данных для локальной подготовки ЭТрН

Дата: 23.09.2026. Контекст для продолжения: [handoff](saby-etrn-handoff-2026-09-23.md). План: [saby-etrn-plan.md](saby-etrn-plan.md).

Используем существующие карточки «Справочники → Автомобили» и «Справочники → Водители». Известные сведения заносим в соответствующие поля по документам, неизвестные оставляем пустыми. Не все поля большой карточки автомобиля нужны для первого сценария ЭТрН. Обязательность внешнего формата определяется отдельно по роли и этапу; наличие пустого поля в интерфейсе не означает, что его обязательно запрашивать.

## Что такое СТС и как читать карточку

**СТС — свидетельство о регистрации транспортного средства.** Это регистрационный документ машины, в котором можно найти её госномер, идентификационные и технические сведения и данные собственника. СТС, ПТС/ЭПТС, госномер и VIN — разные вещи:

- **Госномер** — буквенно-цифровой номер на табличке машины с кодом региона.
- **VIN** — заводской идентификатор транспортного средства, обычно 17 символов; переписывается из документа.
- **Серия и номер СТС** — реквизиты самого свидетельства. В эти поля нельзя вводить госномер или VIN.
- **ПТС/ЭПТС** — паспорт транспортного средства; его реквизиты записываются в отдельный блок.

Для переноса данных можно предоставить читаемые изображения обеих сторон СТС. Реквизиты договора использования машины и подтверждённая грузоподъёмность могут потребовать отдельного источника. Не считать, что один СТС закрывает все сведения для ЭТрН.

## Куда заносить сведения в показанной карточке автомобиля

| Поле CRM | Что указывать | Что уже известно |
| --- | --- | --- |
| Автомобиль / номер | Полный госномер с буквами и регионом | Сейчас у ряда машин здесь короткая подпись вместо полного номера |
| Название для выбора | Удобное название, например «Hyundai 489» | Сохранить существующие понятные названия |
| Марка / Модель | Марку и точную модель по документам | Марки известны; «489» в названии не является моделью |
| Прицеп | Сведения о реально используемом прицепе/полуприцепе | При отсутствии оставлять пустым; цистерна на раме машины сама по себе не отдельный прицеп |
| Объём автомобиля, л | Вместимость цистерны в литрах | Известна для четырёх из пяти машин |
| Секции, л | Объёмы секций, например `5700 + 4528` | Уже заполнены, суммы проверены |
| VIN / Тип транспортного средства | Значения по документам машины | По машине из образца часть сведений уже есть |
| Разрешённая максимальная масса, кг | Именно разрешённая максимальная масса, в кг | Не подставлять сюда вместимость в литрах или грузоподъёмность |
| Масса без нагрузки, кг | Масса машины без нагрузки, в кг | Переписывать по документу |
| Собственник / Адрес собственника | Указанные в документе сведения | Не путать собственника с организацией-перевозчиком |
| Блок СТС | Серия, номер, дата и орган выдачи свидетельства | Заполнять отдельно от госномера |
| Блок ПТС / ЭПТС | Реквизиты паспорта ТС, если они доступны | Не блокировать сбор базовых сведений из-за пустых дополнительных полей |
| Цвет, двигатель, мощность и остальные технические поля | Можно сохранить, если источник доступен | В исходном образце ЭТрН эти поля не образуют обязательный список для первого сценария |

**Поля, которых сейчас нет в структурированном виде и которые предстоит добавить:** грузоподъёмность с явной единицей; тип владения/основание использования; ИНН собственника/стороны документа там, где нужен; название, номер, дата и стороны договора аренды/лизинга/другого основания. У прицепа сейчас одна текстовая строка — полноценная карточка его реквизитов не реализована. До добавления полей собирать сведения по шаблону ниже, а не записывать их в случайные поля автомобиля.

## Шаблон для каждой машины или прицепа

```text
Название в нашем списке:
Полный госномер:
Марка и модель:
Тип транспортного средства:
VIN:
Грузоподъёмность и единица (кг или т):
Источник значения грузоподъёмности:
Вместимость и секции (только если ранее неизвестны или изменились):
Собственник — название/ФИО:
ИНН собственника/стороны договора, если требуется для основания:
Основание использования перевозчиком: собственность / аренда / лизинг / другое:
Если есть договор: название, номер, дата, стороны:
Прицеп/полуприцеп: нет / есть (для него аналогичные сведения):
СТС: фото обеих сторон либо переписанные реквизиты:
ПТС/ЭПТС: дополнительные сведения, если понадобятся и доступны:
Что пока неизвестно:
```

Вместимость в литрах — объём цистерны. Грузоподъёмность — масса груза. Разрешённая максимальная масса — другой показатель. Не считать их взаимозаменяемыми; грузоподъёмность не выводить только из литража. Для расчёта массы груза по формуле `масса_кг = литры × плотность` плотность должна быть в кг/л; если она в кг/м³, нужен пересчёт через 1000.

## Шаблон для каждого водителя

```text
Имя в нашем списке:
Полные ФИО:
Телефон (только если изменился):
ИНН либо водительское удостоверение — серия, номер, дата выдачи:
Основная машина:
Другие машины, на которых работает:
```

В текущей карточке водителя есть ФИО, телефон, машина и паспортный блок, но нет отдельных полей ИНН и ВУ. Эти поля предстоит добавить; паспортные реквизиты не заменяют водительское удостоверение. Полные данные из образца по Олегу уже сохранены приватно.

## Короткое сообщение менеджеру

> Привет! Для ЭТрН пришли, пожалуйста, СТС с двух сторон на машины и прицепы, подтверждённую грузоподъёмность и сведения, кому принадлежат машины. Если перевозчик использует их по аренде/лизингу — нужны реквизиты и стороны договора. По водителям — полные ФИО и ИНН либо серия, номер и дата выдачи ВУ. Телефоны, объёмы и секции уже есть. Подскажи также, кто и через что подписывает ЭТрН за отправителя и перевозчика.

## Что собирается отдельно от карточек водителей и машин

- По конкретному рейсу: участники и роли, фактические места погрузки/выгрузки, груз, масса/объём, способ определения массы, основание перевозки и применимые особые сведения. Используем уже имеющиеся данные, но подтверждаем, что они относятся именно к этому рейсу.
- По подключению: кабинет/организации Saby, поддерживаемый способ авторизации, тариф/права, тестовая среда или выбранный пилот. Секреты настраиваются отдельно на сервере, не в этих заметках.
- По подписанию: кто выполняет действие, чей сертификат используется, каким средством и с какими полномочиями; участие получателя на своём этапе.
- По результату: какой файл и после какого этапа должен быть доступен в CRM. Скачивание существующей №7 и создание новой подписанной ЭТрН проверяются отдельно.

Сначала заполняем сведения для одного пилота и проверяем их по источнику. Заполнение всех справочников не является условием первой проверки чтения существующей накладной через API. Этот файл — инструкция по сбору данных; новые поля и интеграция ещё не реализованы.
