## Какие сведения есть в образце

Ниже состав конкретного документа, а не утверждение, что каждое поле обязательно во всех ЭТрН. Обязательность и альтернативы проверяются при реализации выбранного формата и этапа Saby.

| Блок | Сведения в исходном XML | Как использовать |
| --- | --- | --- |
| Водитель | Фамилия, имя, отчество, телефон; ИНН; серия, номер и дата выдачи ВУ | По Олегу уже есть в образце. Не просить повторно. В образце присутствуют и ИНН, и ВУ; выбор допустимой альтернативы не выводить из одного примера |
| Машина | Полный госномер, VIN, марка/модель, тип ТС | Сверить имеющиеся документы; не просить новый скан, если значение уже читается в переданном источнике |
| Вместимость | Вместимость цистерны | Использовать известный объём, сверяя единицы XML и CRM. Секции полезны для CRM, но отдельного списка секций в блоке ТС этого образца нет |
| Грузоподъёмность | Отдельное значение грузоподъёмности | Нужна подтверждённая масса груза, которую может перевозить ТС. Не подменять полной массой машины или литражом |
| Использование машины | Тип владения; название, номер, дата документа аренды; идентификатор составителя | Для машины Олега реквизиты уже есть. Уточнять актуальность и конкретные недостающие значения, а не заранее требовать полную копию договора |

Проверены узлы `СвВодит` и `СвТС/ТС` первого титула `ON_TRNACLGROT`. В блоке ТС есть `ПарТС` и `ОснАрЛиз`. В четырёх проверенных титульных XML не найдены реквизиты СТС, ПТС/ЭПТС и свидетельств ДОПОГ. Оригиналы остаются приватно вне Git.

## Что убираем из общего запроса

- Серии, номера, даты и органы выдачи СТС и ПТС/ЭПТС, особые отметки и таможенные сведения — дополнительные поля карточки; их заполнение не является условием подготовки по этому образцу.
- Цвет, двигатель, мощность, экологический класс, подробный адрес собственника и прочие технические поля — не запрашиваем ради заполнения всех разделов формы.
- Фото СТС/ПТС с двух сторон и полные копии договоров — используем как источник конкретного недостающего значения, если оно потребуется, а не требуем автоматически по каждой машине.
- Копии ДОПОГ водителя/машины и продлений — исключаем из общего запроса для воспроизведения полей этого образца. Проверка допуска к перевозке опасного груза — отдельная задача; отсутствие реквизитов в образце не устанавливает ненужность документов для самой перевозки.
- Паспорт водителя — не запрашиваем для заполнения блока водителя этого образца. Паспортные поля CRM не заменяют ИНН и ВУ.

Пять ПТС, переданных 28.09.2026, — дополнительные источники уже предоставленных сведений. Не просить их заново и не требовать заполнить весь блок ПТС только из-за наличия этих файлов. Их получение само по себе не означает импорт в CRM.

Все пять файлов просмотрены 28.09.2026: по 700 — четырёхстраничная выписка ЭПТС с текстовым слоем, остальные — двухстраничные сканы ПТС. Из них можно сверять VIN, тип и модель; марку базового шасси не подменять маркой готового ТС. По 442 учитывать особую отметку об изменении массы без нагрузки. Явного объёма цистерны и отдельного подтверждённого значения грузоподъёмности в этих файлах не найдено; обозначение модели и разность масс не использовать вместо них.

## Что уже известно и что требует точечного уточнения

- Данные Олега доступны в исходном XML. Телефон и ИНН Олега не включать в повторный запрос. Наличие значения в документе и наличие отдельного поля CRM — разные состояния.
- Для машин 063, 442, 489 и 700 ранее подтверждены вместимость и секции. Не запрашивать повторно без конкретного расхождения. Историческая сверка не заменяет чтение текущей карточки перед импортом.
- **По 442 значение 27,9 т в поле грузоподъёмности образца спорное:** оно совпадает с ранее подтверждённой полной массой автомобиля. Не переносить его как достоверную грузоподъёмность и не вычислять замену вычитанием масс без подтверждения источника.
- По аренде 442 известны реквизиты из образца. Для будущего документа достаточно сначала уточнить, действует ли прежнее основание; копия договора не является автоматическим условием локальной подготовки.
- По остальным машинам и водителям сначала сопоставить существующие карточки, старые документы и новые ПТС. Запрашивать только оставшиеся поля из таблицы выше с указанием конкретной машины/водителя. Старый список от 25.09.2026 не выдавать за результат новой сверки.

Не переносить реквизиты Олега и его машины на других водителей и автомобили. Для одной машины сохранять одну карточку, даже если на ней работают несколько водителей; фактическую машину выбирать в рейсе.

## Карточки CRM и границы текущей работы

В коде CRM на 28.09.2026 поля СТС, ПТС и паспорта водителя уже необязательны; дополнительные секции свёрнуты по умолчанию. Для сохранения машины требуется поле «Автомобиль / номер», для водителя — имя и существующая машина. Эти проверки сохранения карточки не являются проверкой готовности ЭТрН. Отдельные поля ИНН/ВУ водителя, грузоподъёмности и основания использования ТС пока не реализованы; отсутствие поля в CRM не является поводом повторно запрашивать документ.

Сейчас уточняем постоянные сведения водителей и машин. Получателя, даты, адреса, груз, количество, плательщика и остальные переменные сведения заполняем при создании конкретного документа. Перевозчик ООО «НК АРТЭЛЬ» уже известен; повторно спрашивать его не нужно.

Настройка доступа, подписанты, подключение Saby и проверка полного обмена — следующие отдельные этапы. Они не дополняют текущий запрос по справочникам. Сохранённый образец не подтверждает действующее подключение или завершённый обмен.
