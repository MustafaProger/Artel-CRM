## Изменения

- До ответа сервера панель показывает нейтральное «Документы Saby», а не ошибочную цепочку АРТЭЛЬ → НК → клиенты. После ответа прямой режим показывает НК АРТЭЛЬ → Клиенты.
- GET состояния и документов ограничены 20 секундами. При отсутствии ответа доступны понятная ошибка и повторная загрузка. Ошибка файлов не скрывает уже полученное состояние. Чтение/повтор загрузки не запускают отправку.
- Для прямого режима семь этапов: подготовка, подтверждение водителя, создание ЭТрН, подпись отправителя НК, подпись перевозчика НК, передача клиентам, приёмка клиентами. Подтверждения считаются отдельно по выбранным доставкам. Архив старого обмена не засчитывается в новый черновик. Некорректная дата не подтверждает приёмку ни в шкале, ни в заголовке.
- По явному ответу пользователя правило действует для всех **новых** прямых рейсов НК → клиент: `loadingActorMode=sender`, отдельное лицо «Отгружает», сотрудник и основание погрузки не добавляются. Владелец нефтебазы сохраняется. Старые рейсы, их снимки, факты и разрешения не пересчитываются.
