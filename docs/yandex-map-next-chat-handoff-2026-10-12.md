Новый выбор Яндекса заменяет прежнее согласование OSM. Главный фокус этого чата — карты, не исторический заголовок о Saby. Commit/push и платная подписка/смена тарифа не поручены. Если для реальной интеграции необходима покупка, сначала установить конкретное ограничение и стоимость по официальным источникам; не заменять Яндекс другим провайдером молча.

## Желаемый результат и приёмка

1. Реальный поддерживаемый JavaScript API Яндекс.Карт внутри CRM. Ссылка на Яндекс, подпись или Яндекс-слой поверх прежней OSM-карты не закрывают запрос. Привести к выбранному провайдеру связанные карты выбора точки в заявках/справочниках, если они входят в действующий сценарий; не оставлять незаметную подмену OSM.
2. «Показать всё» действительно возвращает обзор всех активных заявок с известными координатами после ручного приближения/сдвига. Проверить на нескольких разных точках, общей точке с несколькими заявками, одной точке и пустом наборе. Сохранить читаемые карточки с компанией/литрами/адресом/комментарием и мобильное нажатие. Пользовательский дефект пока передан как наблюдение, новая диагностика ещё не выполнена.
3. Создать несколько **явно помеченных временных тестовых заявок** с разным литражом, преимущественно на существующих компаниях и подтверждённых адресах. Разные литры на одном адресе не дают разные географические точки — нужны также разные существующие площадки для осмысленной проверки обзора. Не придумывать реквизиты юридических лиц, если можно использовать существующие справочники.
4. Новое разрешение отменяет прежнее «никаких реальных тестовых записей» только для этих заявок. Не превращать их в рейсы/отгрузки, не отправлять в Saby, не создавать платежи или уведомления сотрудникам. Проверить штатные побочные эффекты создания заявки. Записать точные ID тестовых заявок в приватный реестр для последующего точечного удаления; оставить их пользователю для проверки, автоматически не удалять.
5. Опубликовать с backup и сверкой текущей базы. Проверить именно авторизованный production Chrome: Яндекс-тайлы/элементы провайдера, реальные тестовые метки, работающее «Показать всё» после сдвига/масштаба, карточки desktop/mobile. Сохранить скриншот. HTTP 200 и синтетические тесты не заменяют эту проверку.

Сохранить уже работающую редакцию адреса, приоритет ручной точки, отдельную проекцию координат, защиту версий и исторических снимков. Для геокодинга и хранения результатов проверить совместимость с условиями выбранного Яндекс API по официальной документации; не объявлять бессрочное хранение/бесплатный тариф допустимыми без проверки.
