## Поведение

При разрешённом удалении рейса все его исходные заявки переходят из consumed в active, связи tripId/shipmentId очищаются, версия повышается. Сохраняются идентификатор, автор, клиент, адрес, объём, цена, комментарий, дата и остальные поля заявки. Возврат выполняется в одной транзакции с удалением всех доставок. Учитываются и заявки доставок, ранее удалённых при редактировании этого рейса.

Удалённые отгрузки сохраняют исторический source_request_id. Проверка хранилища допускает повторное использование такой заявки; для действующих отгрузок статус, рейс и доставка по-прежнему проверяются строго. Устаревшие версии, повтор удаления и старый ключ создания не создают дублей. Права удаления, запреты при Saby, фактах убытия/доставки и платежах сохранены.

Рейсы без исходных заявок не создают вымышленные заявки. Ранее удалённые реальные рейсы автоматически не восстанавливались. Реальные удаления и другие бизнес-изменения при приёмке не выполнялись.
