# Saby: предупреждение этапа 7 и стабильность страницы — 02.11.2026

Обе проблемы исправлены локально на свежей production-базе `artel-crm:20261101-stage6-repair-172a07ad`. Публикации, commit/push, изменения реальных документов, подписей, разрешений или данных нет. Изолированные исходники: `.local/saby-ui-fix-20261102/source`. Основной checkout и чужие изменения сохранены.

## Изменения

- `exchangeEtrn` при read-only refresh сохраняет предыдущий статус до результата чтения. Существующие unknown/error и lastError остаются видимыми. Успешный readback очищает ошибку штатным способом; неудачный сохраняет новую ошибку. Создание, повторная отправка, leases и защитные проверки не ослаблены. Классификатор ошибок не менялся: завершённость рейса не скрывает проблемы этапа 7.
- Закрытый список обновляет индикаторы каждые 30 секунд и при возвращении на страницу. Фоновое чтение не переставляет карточки и не размонтирует панели. Более старый ответ списка не затирает более свежий результат открытой панели. Ограничены параллельные запросы, добавлены abort/timeout; неудачное фоновое чтение сохраняет последние сведения.
- Панели Saby открываются независимо: соседняя раскрытая панель не схлопывается. Повторное нажатие закрывает выбранную панель. Асинхронное содержимое исключено из браузерных scroll anchors.
- Красная подсветка не добавляет размеры заголовку. На мобильном расположение строки действий не зависит от наличия ошибки, поэтому снятие предупреждения не перестраивает карточку.
- Доступные названия регионов Saby, подписания, погрузки и ответа НК включают номер рейса. Соответствующие селекторы прежних UI-проверок адаптированы.
