## IP, VPN и документация банка

- Внешний IP определяется запросом из той среды, где работает серверный код CRM. `localhost` — адрес локальной CRM, его нельзя использовать как внешний адрес доступа банка.
- Для ручной проверки: `curl -s https://api.ipify.org`.
- В инструкции выпуска банк требует статические IP; можно указать несколько адресов, до девяти. При изменении IP или прав требуется новый токен.
- Официально допускается отключение проверки IP через поддержку банка с указанием ИНН. Только после подтверждённого отключения при новом выпуске можно использовать техническое значение вроде `0.0.0.0`.
- Эта альтернатива была предложена пользователю, но запрос на отключение не отправлялся, и отключение не подтверждено. Не вводить `0.0.0.0` как способ самостоятельно снять ограничение.
- Для начального чтения счетов, выписок и PDF используются методы с Bearer-токеном; отдельный клиентский mTLS-сертификат для них в изученной документации не требуется. Не путать клиентский mTLS с проверкой TLS-сертификата сервера.
- H2H-токен по изученной инструкции действует 90 дней после последнего использования; при постоянном использовании остаётся активным.
- В письме поддержки было сказано об отсутствии отдельных API-лимитов, однако страницы методов содержат ограничения частоты запросов. Например, счета v4 — 6 запросов/с, выписка — 20/с, PDF — 1/с. При реализации учитывать документацию конкретного метода.
- Метод `payment/status` возвращает статусы черновиков, созданных через API; он не заменяет выписку и не является списком всех движений по счёту.
