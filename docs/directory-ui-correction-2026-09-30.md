# Исправление справочников по уточнению пользователя — 30.09.2026

Пользователь уточнил, что под перевозчиками в повседневной работе подразумеваются наши водители, и попросил убрать общую вкладку компаний и кнопку очистки. Новые отдельные вкладки компаний и перевозчиков были лишними для этого процесса.

## Что изменено

- Убраны из интерфейса вкладки «Компании», «Перевозчики» и кнопка «Очистка справочников». Остались отдельные клиенты, поставщики, нефтебазы, менеджеры, товары, автомобили, водители и места погрузки/доставки.
- В рейсе выбирается водитель. Автомобиль подставляется только из явно указанного `driver.vehicleId`; пользователь может выбрать другую существующую машину. Отдельного выбора компании-перевозчика, обязательности этого выбора и скрытой фильтрации водителей по компании больше нет.
- В карточках водителя и автомобиля также убран выбор компании-перевозчика. Прямая настройка автомобиля водителя остаётся.
- Реквизиты участников нефтебазы можно добавить/изменить прямо рядом с соответствующей ролью. Дочерняя карточка не теряет несохранённый черновик нефтебазы. Три роли остаются независимыми, юридический адрес не подменяет фактический.
- Поиск организации в контексте нефтебазы/адреса начинается с имени или ИНН и не раскрывает весь смешанный каталог при пустом запросе.
- Существующие клиенты, поставщики, машины, водители, банковские контрагенты, связи и история не удалялись. Новых миграций и массовых исправлений базы нет. Внутренняя модель компаний необходима для реквизитов клиентов/поставщиков/участников; отдельного общего экрана больше нет.

Исторический `carrier_id` сохраняется при обычной смене водителя, автомобиля и добавлении доставки. Юридический перевозчик Saby остаётся настроенной организацией; личность водителя не превращается в юридическое лицо. Явное противоречие сохранённых юридических связей проверяется перед отправкой. Старый API с явной компанией остаётся совместимым.
