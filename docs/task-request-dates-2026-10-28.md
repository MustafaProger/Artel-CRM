# Задачи и даты заявок — 28.10.2026

По поручению пользователя выполнены локальные изменения с последующим commit/push и выпуском на сервер.

- В задачах убран срок из редактора, карточки и календаря. Старое значение в данных сохранено; напоминания действуют как прежде.
- В списке задач отдельная галочка выполнения. Повторное снятие возвращает в работу. Сохранение через прежний API с проверкой версии и прав; ошибка не показывает ложный успех. Карточка открывается отдельно, доступна клавиатура, область галочки 44px. В архиве галочка недоступна.
- В заявках дата выполнения, редактирование и отображение. Новая форма предлагает сегодня по Москве; дату можно очистить. Сначала ранние даты, при равенстве прежний порядок, без даты — в конце. Старые записи не мигрируются. API валидирует календарную дату, сохраняет при старом PATCH без поля, учитывает её при повторном создании.
