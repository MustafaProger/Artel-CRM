# Индикация ошибок ЭТрН

При сохранённой ошибке под значком машины и названием рейса появляется красная подложка. Слева от «Изменить рейс» выводится краткое действие: «Дополнить данные», «Проверить подпись», «Проверить связь» или «Проверить этап N». Вся карточка сохраняет обычный фон. Подробности доступны в панели Saby; проблемный этап отмечен красным номером. Обычное ожидание подписи не считается ошибкой.

Список получает безопасную проекцию ошибок из уже прочитанного хранилища. Права на рейс проверяются прежним способом; внешних запросов и записей при проекции нет. После получения состояния без ошибки оформление очищается.

Проверка: TypeScript/frontend build, целевой ESLint, 36 unit-тестов; Chromium/WebKit 375 и 1440 px — карточки с ошибкой/без ошибки, обычная и прямая ЭТрН, очистка предупреждения, отсутствие горизонтального переполнения и ошибок JS. UI проверен на синтетических данных.

Локальный пример: `node --import tsx scripts/preview-trip-errors.mjs`, затем http://127.0.0.1:5197/__preview → «Рейсы». Проверка UI: `node scripts/verify-trip-errors.mjs` при работающем примере. Пример использует временное синтетическое хранилище и отклоняет изменяющие API-запросы.

Изменение подготовлено на сохранённой ветке опубликованной auth-performance версии. Совпадение всех изменяемых исходных файлов с локальной базой carrier-recovery проверено. Публикация в production не выполнялась; перед публикацией требуется свежая сверка текущего выпуска.
