# Карточки карты и прошлые даты — локально, 29.10.2026

По поручению пользователя подготовлен вариант для личной проверки. На сервер не публиковался; реальные данные, доступы и внешние интеграции не менялись. Commit/push не выполнялись.

## Изменения

- Название и адрес слева, объём справа; дата выполнения — отдельной строкой под адресом, мелкой вторичной типографикой. Карточки не растягиваются по высоте соседней длинной карточки. Две колонки при достаточной ширине содержимого, одна до760px; кнопки/ссылки сохраняют 44px по высоте.
- На карте активные заявки с корректной датой выполнения **до завтра включительно**, без нижней границы. Все прошлые даты, сегодня и завтра по Москве. Будущие после завтра и без даты остаются в списке; consumed/cancelled не возвращаются. Нефтебазы сохранены, группировка/цвета считают вошедшие заявки. При смене московских суток прошлые остаются, новая завтрашняя дата включается.
- Исправлена обнаруженная проверкой доступности ссылка маркеров aria-controls на отсутствующий DOM-элемент: контейнер подробностей существует и при закрытой карточке.
- Кэш синтетического Vite-стенда изолирован в его временном каталоге. При первом открытии обычного Chrome общая оптимизация зависимостей параллельных стендов вызвала `options.view.then is not a function`; после изоляции карта, маркеры и карточки открываются. Диагностический console.error удалён из исходников.

## Проверка

Lint, TypeScript, frontend/backend build PASS. 16 целевых тестов дат/точек/обзора/polling PASS. Исходная и собранная версии: по20 групп Chromium/WebKit, по14 axe WCAG2A/AA+2.1A/AA на320/375/390/640/768/1024/1440px, ошибок JavaScript и внешних запросов0. Проверены геометрия длинного названия/адреса/даты/объёма, клавиатура, открытие точки, редактирование/отмена, URL, московская полночь при America/Los_Angeles и пустой список с сохранённой нефтебазой.

Регрессия задач/дат: 25 групп и16 axe, сохранение/повторное чтение дат, конфликт задачи, скрытый срок, напоминание и перезапуск синтетического runtime PASS. Первоначальный axe-сбой aria-controls сохранён в ui-source-initial.log и ui-source-initial-report.json, устранён и перепроверен. Chrome пользователя: карта содержит прошлый месяц/вчера/сегодня/завтра, пример со скриншота визуально проверен; вкладка оставлена открытой. Физический телефон не проверялся.
