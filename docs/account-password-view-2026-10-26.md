# Просмотр вновь заданных паролей — 26.10.2026

## Согласованное поведение

Пользователь выбрал: сохранять для просмотра только вновь заданные пароли; существующие не менять. Автоматического сохранения пароля при входе нет.

В «Сотрудники и доступ» у аккаунтов с новым сохранённым паролем есть кнопка «Показать пароль». У прежних аккаунтов — «Пароль недоступен для просмотра: задан ранее». После явной установки нового пароля будет доступен именно он. Это относится к сотрудникам и водителям, включая автоматически сгенерированные пароли при выдаче/сбросе водительского доступа.

Просмотр следует существующему праву раздела `accounts`; новых прав пользователям не выдаётся. Пароль запрашивается отдельным POST с версией пользователя, ответ не кешируется. Несуществующие, удалённые, устаревшие версии и запросы без необходимых прав отклоняются. Пароль скрывается по кнопке, через 30 секунд, при потере фокуса окна и скрытии вкладки.

## Хранение и совместимость

Проверка входа остаётся на scrypt. Для просмотра добавляется `passwordCiphertext`: AES-256-GCM, случайный IV, аутентифицированная привязка к salt/passwordHash. Отдельный серверный `ARTEL_ACCOUNT_PASSWORD_KEY` находится вне Git, сборки и базы; его необходимо сохранять при следующих выпусках. Пароль не возвращается в списке пользователей, сессии или общем снимке. Ошибка ключа или повреждённый ciphertext не возвращают пароль. Смена пароля и отзыв сеансов продолжают работать.

Установщик ключа сохраняет исходную конфигурацию в закрытой резервной копии и добавляет только отсутствующий ключ под существующими runtime-блокировками. Значения ключей и реальные пароли в отчёт не входят. Старый backend поверх новых passwordCiphertext не возвращать; совместимое восстановление использует тот же новый код без восстановления старых данных.
