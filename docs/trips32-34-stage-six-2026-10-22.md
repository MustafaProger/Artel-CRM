## Исправление

- Версионный протокол для новых заявок с водительским сценарием; старые неизвестные попытки требуют адресного продолжения.
- Нативная ЭТрН привязывается по взаимным ссылкам с заявкой. Все грузы сверяются с замороженными доставками, затем существующий документ используется для первой доставки. Исходный XML сохраняется полностью.
- Для остальных доставок передаётся полный неподписанный T1; номер присваивает Saby. Перед каждым созданием сверяется полный состав уже связанных документов.
- Запись существующего документа содержит его верхний ID, вложенную адресацию с редакцией и ID вложения. Потеря ответа ведёт к чтению результата, а не повторной записи.
- Отдельное согласование электронного уведомления связано с текущим рейсом, попыткой и сохранённым разрешением на подпись. Подписывается проверенный подготовленный XML Saby, привязанный к хешу сохранённого задания.
- Другие прямые рейсы, в том числе №31, не являются объектом восстановления.

Официальные описания API: [запись документов](https://saby.ru/help/integration/api/all_methods/doc), [порядок обмена](https://saby.ru/help/integration/api/doc_guide), [модель документа](https://saby.ru/help/integration/api/model_data).
