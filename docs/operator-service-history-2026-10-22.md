## Поведение

- Desktop-столбец «Получатель» ограничен 500 CSS px, имеет обе вертикальные границы. Длинные строки прокручиваются горизонтально внутри своей ячейки с клавиатуры/трекпада; ширина таблицы больше не растягивает эту колонку. Мобильные карточки сохраняют переносы текста.
- В карточке сервиса доступны шесть прежних цветов, произвольный цвет и предпросмотр. Для произвольного фона контрастный чёрный/белый текст выбирается по относительной яркости. Цвет сохраняется сервером и проверяется при чтении хранилища.
- Журнал, меню действий и поле сервиса используют актуальное название/фон по стабильному serviceId. Сохранённые снимки операций не переписываются. Наследованные записи без serviceId не связываются с переименованным сервисом по догадке.
- По прямому ответу пользователя новая скидка не пересчитывает существующие операции, в том числе сегодняшние. Для новых операций применяется ставка на дату заправки; граница изменения — календарный день Москвы. Дата и выбранный сервис пересчитывают новую автоматическую сумму. Сервер самостоятельно проверяет ставку и версию справочника.
- История ставок начинает фиксироваться при следующем изменении скидки; начальное значение — известная ставка до изменения. Утраченная до этого история справочника не реконструируется. Повторная смена в тот же день задаёт последнюю ставку для новых операций этого дня; сохранённые операции сохраняют собственную ставку/сумму.
- Изменение только названия/цвета не создаёт новый период скидки. Обычное редактирование существующей операции с прежним сервисом сохраняет её финансовые условия.
