### Причина отсутствия автоматического старта после исправления

`server/local-api.ts:945` вызывает `enqueueAutomaticTripSaby` только при первоначальном создании (`currentActor && !id && !replayed`). Редактирование существующего рейса сознательно не создаёт новое разрешение обмена под текущей политикой. Поэтому после отказа валидации при исходных 1 л PATCH на 10 л исправил данные, но не записал `autoAuthorization`. Текст UI «При сохранении рейса ... автоматически» не учитывает этот случай. Повторное сохранение без изменения кода/явного штатного запуска не решает проблему. Это ещё не проверка доступности ключа Saby.
