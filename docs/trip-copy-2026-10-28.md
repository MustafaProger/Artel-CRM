# Копирование рейса — 28.10.2026

Две кнопки копирования добавлены к каждой карточке «Рейсы → В процессе», включая фильтры «Завершённые» и «Все». Иконка списка копирует сводку с ценами, грузовик — задание для водителя. По последнему уточнению пользователя видимый текст на кнопках убран: назначение сохраняется в подсказке и доступном имени. Кнопки 44×44 px стоят рядом, доступны в свёрнутой карточке, отделены от раскрытия, поддерживают клавиатуру и сообщают об успехе. При отказе Clipboard API показывают выделяемый текст для ручного копирования; повторная попытка доступна.

## Формат

```text
23.10
Комплекс Ойл 77000
ДТ
4000 л Ип Киртока 70,00
5500 л ооо спс 73,00
8000 л ао АиФ 72,00
Пётр 8000+7000+8000
```

Дата — сохранённая дата рейса без пересчёта часового пояса. Поставщик и водитель — имена из доступных справочников. Цена поставщика — `purchase_price_unspecified_unit` (рубли за тонну в форме рейса). Товар — отдельная строка по явному шаблону пользователя. Клиенты идут в сохранённом порядке: `quantity_litres`, название, `sale_price_per_litre` с двумя знаками после запятой. Последняя строка содержит `transport_amount` каждой доставки в рублях без сокращения тысяч, через «+», без суммирования. Нули сохранены; неизвестные значения обозначаются явно. Переводы строк внутри названий заменяются пробелами.

## Реализация и просмотр

### Текст для водителя

```text
Погрузка на ВЛПДС от ВСК-Трейд

Бетон-Крафт 5500 л
Адрес клиента
https://yandex.ru/maps/-/CXbEvMOg
Приёмщик 79919688774

джи аш трейд 12000 л
Адрес клиента
https://yandex.ru/maps/-/CXbEvClB
Владимир +7 968 757-09-09
```

Это пример формата из запроса, а не изменение реальных данных. Цены и стоимость доставки в задание водителю не включаются. Адрес и карта берутся из сохранённого рейса, приёмщик — из связанного адреса именно этого клиента. Для старых записей без снимка адреса допускается соответствующая запись справочника. При отсутствии ссылки используются сохранённые координаты или явно подписанный поиск адреса в Яндексе; отсутствие телефона/адреса отмечается текстом.
