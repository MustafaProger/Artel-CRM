## Изменения

1. Выбранный сервис в новой операции окрашивается цветом из справочника, с контрастным текстом и цветной меткой.
2. «Сверка дня»: дата, все сервисы справочника, литры/сумма CRM, ручной отчёт кабинета и разница. Есть переход к операциям дня и история ручного отчёта с автором. Нули допустимы, отсутствие отчёта показано отдельно. Запись защищена правами, версией и ключом повторного запроса; одна сверка на дату/сервис.
3. В возвратах и ожидающих заправки видна цена за литр. Подробности включают исходный литраж, сумму, группу при наличии, клиента/задание, получателей/реквизиты и комментарий операции. Исходные события сохранены.
4. Подтверждение закрытия формы компактное, без лишних элементов; мобильные карточки сверки проверены по ширине и контрасту.
5. Постоянная кнопка «Обновить задания и справочники» удалена. Только при реальном конфликте версии предлагается загрузить актуальные данные с сохранением ввода.
6. Новая операция открывается из уже загруженных данных без повторного GET. Сервер по `Prefer: respond-async` подтверждает сохранённую операцию до завершения отправки push. Событие уведомления остаётся в устойчивой очереди, прежний контракт для других клиентов сохранён. Отдельный тест удерживает отправку провайдера и подтверждает доступность сохранённой операции.
7. «Уведомления включены» требует разрешения браузера и подтверждённой регистрации. Учтены отзыв разрешения, отказ регистрации и истёкшая подписка. Тест уведомления возвращает ID сразу после сохранения проверки; UI отдельно получает подтверждение браузера либо ошибку провайдера. Готовая квитанция устройства имеет приоритет над ошибкой отправки. Реальная доставка на телефон не проверена и не заявляется.
8. Вкладки общих справочников соответствуют выданным галочкам. Клиенты/адреса показываются при доступе к обзору, отгрузкам или рейсам. Сотрудники — только с соответствующим разрешением. Для профиля «работа + операторская + справочники/сервисы» видны только сервисы. Серверные проверки и связанные данные для работы сохранены.

## Расчёт сверки

Формула по явному примеру пользователя: **31 500 × 1,10 = 34 650**, при 8% — **34 020**. Процент берётся из снимка операции, первоначально выбранного из справочника, чтобы новые тарифы не переписывали прошлые дни. Каждая сумма округляется до копеек, затем суммируется с Decimal. Разница = CRM − отчёт кабинета.

Включены все неудалённые операции по дате заправки независимо от отметки оплаты; это явно указано в «Как считаются итоги». Литры берутся из операций. Сверка не подменяет оплату, факты заправки, возврат или перенос остатков. Данные Google Sheets прочитаны через подключение Google Drive (лист «Сверка », gid1532933571); в таблицу ничего не записывалось.
