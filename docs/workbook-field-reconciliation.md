Изменено отображение уже сохранённых значений. XLSX, JSON-источник, ID компаний и операций, денежные значения и рабочие изменения не переписывались. Исторические поля доступны для чтения; форма создания многоклиентской отгрузки продолжает работать по правилам общей машины.

Связь банковских платежей, правила прибыли и нумерации не менялись. Сводные блоки над строками отгрузок остаются в исходной выгрузке `company_summaries.json`; они не являются отдельными полями отгрузки.
