## Граница продолжения

Форма на скриншоте сохраняет доступ для будущей настройки; автоматический адаптер Яндекса в CRM пока отсутствует. Повторное сохранение логина и пароля не исправляет отказ веб-метода с интеграционным токеном.

Нужны подтверждённые Яндексом метод текущего денежного остатка договора и серверная авторизация без браузерной сессии сотрудника. После успешного реального чтения можно реализовать адаптер, проверить его на синтетических сценариях и выполнить узкий выпуск. HTTP 401 не доказывает отсутствия закрытого API у провайдера.
