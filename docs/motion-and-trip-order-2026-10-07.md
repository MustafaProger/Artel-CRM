# Анимации и порядок рейсов — 07.10.2026

По поручению пользователя исправлены движения интерфейса на мобильных устройствах, появление и закрытие всех модальных окон, порядок новых рейсов в CRM и кабинете водителя.

## Изменения

- Общий `useDialogMotion` обслуживает 17 native dialog в 16 файлах: открытие 220 мс, закрытие 170 мс, затем удаление из DOM. Банковские панели движутся справа; обычные окна — с коротким вертикальным смещением. Фон также плавно появляется и исчезает. Прерывание начинается из текущего визуального положения.
- Сохранены Escape, подтверждение несохранённого ввода, блокировки повторной отправки, фокус, вложенные окна и блокировка прокрутки. Меню использует ту же блокировку; Escape не закрывает одновременно окно и меню под ним. Сохранение/удаление завершают переход до переключения родительского экрана.
- Общие кнопки отвечают на касание, страницы, первые карточки и списки выбора плавно появляются. Контейнер страницы не трансформируется, поэтому фиксированные окна не меняют систему координат. Системное уменьшение движения соблюдено. Палитра, форма полей и таблица отгрузок сохранены.
- У водителя переход анимирует отдельную область содержимого. Настройки уведомлений и ожидание подтверждения устройства остаются смонтированными при переходах между рейсом, списком и архивом.
- Оба кабинета сортируют рейсы по времени создания, новые сверху. API только добавляет читаемое `createdAt`, вычисленное по самой ранней оставшейся доставке. Изменение плановой даты и обычное редактирование не поднимают старый рейс. После создания в CRM открывается первая страница без поискового фильтра. Для исторических записей без времени есть стабильный порядок по дате/ID. Полная замена всех исходных доставок использует время оставшихся строк; отдельная запись создания рейса не вводилась.
- Проверка справочников выявила старое смешение типа адреса с вкладкой сотрудника: исправлены открытие и удаление карточки адреса. В окне удаления сотрудника сохранён первоначальный фокус поля подтверждения.
