Пользователь подтвердил запуск полной цепочки при сохранении готового рейса и отсутствие согласия на каждый документ. Для будущих ответов НК поле «Расчёт платы» должно содержать ровно **«По договору»**. Стоимость, НДС и прочие условия не изменяются. ## Проверка существующей №11 до 16:03 МСК

Текущее чтение API подтвердило выбранную подпись АРТЭЛЬ и неизменность её исходного файла. Ответ НК остаётся неподписанным на этапе «Утверждение», состояние 10; его редакция, этап и подготовленный файл совпадают с прежним манифестом. Доступное действие «Утвердить» объявляет выбранный сертификат с `Ключ.Тип="Отложенный"`, `Активирован="Да"`. Полная предварительная проверка старого манифеста выполнена только чтением и прошла. Это не подтверждает доступность закрытого ключа и не восстанавливает потерянную причину прежней неуспешной попытки.

В открытой пользователем форме Saby видно «По договору», но сохранённый подготовленный XML пока не содержит `РазмПлатРасчет`. Чтение служебных этапов по конкретному документу с `Блокировать="Нет"` вернуло пустую очередь. Пустая очередь характеризует текущую видимость; она не доказывает, что исторический Execute никогда не отправлялся.

Дополнительный `СБИС.ИнформацияОСлужебныхЭтапах` для НК вернул `ПрекратитьЗапросы="Да"`. По документации это означает недостаточные права текущего API-пользователя на служебные документы либо отсутствие назначения обработчиком. При таком ответе пустая очередь не позволяет исключить скрытое задание. Это **не равнозначно запрету бизнес-действия Execute**: постановка на отложенную подпись и обработка служебного этапа имеют разные права.

В первой диагностической обёртке не был разрешён read-only метод `sabyCertificate.List`, из-за чего её собственный запрет был представлен клиентом как транспортная ошибка. После исправления allowlist полная диагностика прошла; эти первоначальные ошибки не являются доказательством сетевого сбоя Saby.

## Исправления

- Правило `paymentCalculation="По договору"` закрепляется при создании новой цепочки. Старые `carrierFill` без этого поля не получают его задним числом.
- Заполняется только `РазмПлатРасчет/@Расчет`. Уже заданное отличающееся условие, ручная правка или заменённое вложение останавливают автоматическую перезапись. Стоимость, НДС и валюта сохраняются.
- Если ответ уже полностью совпадает с ожидаемыми сведениями, отдельное повторное чтение позволяет сохранить подтверждённый манифест заполнения без внешней записи; раньше такой ответ мог остаться без необходимого для подписи `intent`.
- Для новых подготовленных манифестов отметка реальной попытки Execute отделена от предварительного чтения. Сохранение намерения отправки происходит после проверки файлов, авторизации и прав непосредственно перед HTTP. Только доказанное `not_sent` допускает продолжение с теми же ID, редакцией, именами и SHA-256 без повторного Prepare. Исторические попытки без нового маркера автоматически не повторяются.
- Диагностика сохраняет только контролируемые названия методов, фазы, категории и числовые коды. Исходные сообщения, XML, ссылки, реквизиты и stack trace провайдера в рабочие ошибки не попадают.

## Формат и механизм Saby

Встроенное в официальную XSD правило Schematron `0001.006.406.020` требует блок расчёта платы при согласии перевозчика. Обычная проверка XSD не исполняет Schematron. Отдельные тесты исполняют три правила оплаты: текстовый способ расчёта проходит без добавления цены/НДС. Отсутствие блока — подтверждённая проблема формата, но причинная связь с потерянной ошибкой №11 не доказана.

Формат Execute уже соответствовал [официальному API](https://saby.ru/help/integration/api/all_methods/make_doc): массив одного действия, конкретные редакция/этап и отложенный режим. Само выполнение «Утвердить» запускается API. [Отложенное подписание](https://saby.ru/help/integration/api/sequence/delegate/doc) может перейти в состояние 23 и зависит от доступной среды Saby с ключом. Полное завершение устанавливается лишь после подписи всех подготовленных файлов выбранным сертификатом и состояния 7.

Правила чтения очереди: [СписокСлужебныхЭтапов](https://saby.ru/help/integration/api/all_methods/stage_doc), [ИнформацияОСлужебныхЭтапах](https://saby.ru/help/integration/api/all_methods/info_doc). Проверка не блокирует чужие задания и не обрабатывает документы вне выбранной заявки.
