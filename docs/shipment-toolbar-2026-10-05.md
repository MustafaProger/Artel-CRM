# Панель отгрузок — 05.10.2026

По прямому поручению пользователя оформление распространено на показанную верхнюю панель «Отгрузок»: меню, заголовок, поиск, действия, переключатель типов, фильтры, CSV и сброс ширины. Цвета, порядок контролов и логика сохранены. Таблица, её ячейки, колонки, сортировка и редакторы не изменены.

## Реализация и проверки

- `shipments-toolbar.css` использует общие токены размеров и скруглений. Все селекторы ограничены панелью над таблицей.
- «Бензовозы / АЗС» используют существующий `ScrollableSegments`: стрелки, Home/End, показ выбора и reduced motion. Обработчики смены типа прежние.
- `npm run lint`, `npm run build` прошли. Существующее предупреждение Vite о размере JS bundle остаётся.
- `npm run test:design-consistency` и `QA_WEBKIT=1 npm run test:design-consistency`: по 52 состояния в Chromium/WebKit, ноль нарушений axe, ошибок браузера, переполнения страницы, внешних обращений и браузерных записей.
- Поиск/очистка, организация/сброс, CSV, переключение типов и клавиатура проверены на синтетических данных. Меню тестируется клавиатурой: WebKit не фокусирует кнопки при pointer click, поэтому проверка возврата фокуса явно открывает меню через Enter.
- Сравнены таблица и все её потомки при включённых/выключенных новых стилях: 329 элементов при 1440 px, по 299 при 760/390/320 px — одинаковые стили, размеры и координаты относительно таблицы. Изменение высоты разрешённой панели может сдвигать таблицу целиком; оформление самой таблицы неизменно.
- Скриншоты desktop/mobile просмотрены. Артефакты: `qa/apple-consistency-20261005/` и `qa/apple-consistency-20261005-webkit/`, вне Git.
