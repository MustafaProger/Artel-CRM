## Причина и исправление

Высокая карточка перекрывает точку. Нативный OpenLayers-маркер получает `mouseleave`, но React `mouseenter` карточки не обязательно отменяет таймер закрытия при таком переходе. Карточка исчезает, маркер вновь получает наведение — цикл повторяется. Синтетическое воспроизведение до исправления зарегистрировало **12 открытий и 11 закрытий за две секунды** неподвижного наведения.

Перед скрытием теперь проверяются фактическое положение курсора и фокус внутри точки/карточки. Вход через `mouseover` отменяет таймер; уход фокуса из карточки запускает проверку закрытия. Нажатие/Escape и закреплённая карточка сохраняют своё поведение.

Дополнительно сенсорный тест выявил открытие карточки при фокусе до события click: она могла перехватить касание точки. Предпросмотр по фокусу теперь открывается только при `:focus-visible`; касание открывает закреплённую карточку обычным click. Внешний вид, размещение карточек, координаты, данные и правила заявок не менялись.
