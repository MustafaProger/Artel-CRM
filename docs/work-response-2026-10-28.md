# Отклик и оформление задач — 28.10.2026

По скриншотам и поручению пользователя исправлены скорость переключения галочки и строка задачи. Разрешены локальная работа, commit/push, проверка и выпуск на сервер.

## Изменения

- Галочка и состояние строки реагируют сразу. Пока сервер сохраняет — «Сохраняем…», повторный запрос заблокирован. Успешный PATCH сразу разблокирует строку без второго GET всего раздела. Ошибка/конфликт возвращает подтверждённое состояние и показывает причину рядом с задачей; при неизвестном результате предлагается обновление.
- Старый GET отменяется до переключения и не перезаписывает ожидающее состояние. Фоновое чтение пропускается во время сохранения, интервал30с, снят лишний обработчик window.focus; обновление при возвращении во вкладку сохранено. Порядок по созданию стабилен при переключении статуса.
- Галочка выровнена с заголовком, область44px, зелёная отметка вместо тусклого стандартного квадрата. Статус справа на desktop и ниже текста на мобильном, выполненный заголовок зачёркнут. Убраны пустые «Комментариев:0 / Файлов:0», общие разделители строк и аккуратный фокус клавиатуры. Напоминания и редактор сохранены.
- Work GET/PATCH используют ту же свежую сборку компаний/отгрузок и структурную валидацию, но без денежных пересчётов, банковских распределений и сводок. Права остаются в прежнем scopeSnapshot/mutateWork. Только PATCH из version/status пропускает немедленную попытку отправки уведомления о назначении: такое изменение не создаёт нового назначения. Назначение другому сотруднику и расписание push прежние.
