## Найденное различие с предположением адаптера

Опубликованный `verifyOrganizations()` ищет заказчика и перевозчика в одном кабинете. Реально в каждом кабинете возвращается только своя организация. [Официальный список организаций](https://saby.ru/help/integration/api/all_methods/company/) относится к текущему аккаунту; отсутствие перевозчика в кабинете заказчика не доказывает отсутствие доступа к отдельному кабинету перевозчика.

Локальное исправление добавляет явный `SABY_CARRIER_ACCOUNT_NUMBER` и отдельную сессию для проверки перевозчика, сохраняя все операции с заказами в основном кабинете. Исправление и его проверки пока не являются публикацией на сервере. Отдельный набор Saby прошёл 22/22 теста, TypeScript, ESLint и production build завершились успешно. Полный набор API также прошёл: 285/285, без пропусков и ошибок. Все автоматические проверки использовали синтетические данные, реальные проверки чтения описаны отдельно выше.
