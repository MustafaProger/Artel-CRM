# Ошибки обработки ЭТрН — локально, 01.11.2026

По уточнению пользователя: восклицательные знаки и большой блок ошибки из карточки убраны. Фон карточки обычный; красным выделяются только значок машины и название рейса. Слева от «Изменить рейс» — короткая подпись без переноса («Дополнить данные», «Проверить подпись», «Проверить связь» или «Проверить этап N»). Подробности остаются внутри Saby, номера проблемных этапов выделены красным. Во вкладке «В процессе» также выделяется название и показывается краткая подпись.

Покрыты обычная заявка и прямая ЭТрН НК: ошибки создания/отправки, блокировка и неопределённый результат подписания, заполнение ответа НК, ошибки документов доставок и автоматического запуска. Обычное ожидание подписи не подсвечивается. История ошибок не используется; после получения состояния без ошибки индикатор очищается.

Список получает только безопасную проекцию сохранённых ошибок вместе с существующим GET рейсов. Новых чтений хранилища, внешних вызовов, подписей и изменений workflow нет. Проверка полных прав на рейс сохранена. Подробные блокеры подготовки становятся доступны из прежнего ответа панели Saby.
