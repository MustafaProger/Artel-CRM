# Уведомления в Артель CRM

Сейчас в «Работе» сохраняются напоминания с датой и временем и показываются в календаре. Отправка системных push-уведомлений пока не подключена.

Чтобы уведомления приходили и при закрытой CRM, нужен Web Push:

1. Добавить manifest приложения и service worker. Service worker принимает push и показывает уведомление; нажатие открывает нужную задачу в CRM.
2. Добавить кнопку «Включить уведомления». Только после нажатия запрашивать разрешение браузера и сохранять подписку устройства для текущего сотрудника через защищённый API. Предусмотреть выключение уведомлений.
3. На сервере настроить ключи VAPID и отправку назначенному сотруднику при наступлении `reminderAt`, назначении задачи и новом комментарии. Состав событий можно выбирать в настройках.
4. Планировщик выбирает наступившие напоминания, проверяет актуальные права и исполнителя, исключает завершённые/архивные задачи, сохраняет отметки доставки и повторяет временно неудачные попытки. Просроченные подписки удаляются.
5. Текст на экране блокировки лучше сделать нейтральным: «Напоминание по задаче», а подробности открыть после входа. При выходе отключать подписку этого устройства для учётной записи.

На iPhone/iPad веб-приложение нужно добавить на экран «Домой», открыть с его значка и нажать «Включить уведомления». Запрос разрешения должен следовать действию пользователя. Системные настройки, режим фокусирования и доступность сети могут задерживать доставку.

Один только таймер JavaScript или `new Notification()` не обеспечивает доставку при закрытом приложении. На мобильных устройствах уведомления следует показывать через service worker `showNotification()`.

Официальные источники: [WebKit: Web Push на iOS и iPadOS](https://webkit.org/blog/13878/web-push-for-web-apps-on-ios-and-ipados/), [MDN: Notifications API](https://developer.mozilla.org/en-US/docs/Web/API/Notifications_API/Using_the_Notifications_API).
