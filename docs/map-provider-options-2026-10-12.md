# Варианты карты для CRM — 12.10.2026

После проверки тарифа пользователь попросил исследовать альтернативы на время своего отсутствия. Нынешняя карта его не устраивает; он назвал её украинской и сообщил, что не хочет её ставить. В исследовании отдельно проверены происхождение библиотеки Leaflet и данных OSM — это разные компоненты. Новый способ подключения пока не выбран. Платные услуги, обращения провайдерам и новый выпуск не выполнялись.

## Рекомендация

**Яндекс Tiles API + OpenLayers** — наиболее подходящий бесплатный кандидат для карты заявок. Картографическое изображение будет настоящим Яндексом; Leaflet и OSM-подложку можно полностью убрать. Метки, карточки, обзор и выбор точки реализуются внутри CRM через OpenLayers. Это **не нативный JavaScript API Яндекса**, который требовала исходная передача: вариант предлагается явно, без подмены результата.

Яндекс в [официальном сообщении от 18.06.2025](https://yandex.ru/company/news/01-18-06-2025) прямо описывает бесплатный Tiles API для CRM и размещение заказов клиентов логистической компании на карте. [Страница продукта](https://yandex.ru/maps-api/products/tiles-api) подтверждает постоянный бесплатный доступ и совместимость с OpenLayers.

[Действующие условия, п. 6.5](https://yandex.ru/legal/maps_api/ru/) разрешают Tiles в закрытых и коммерческих системах с собственными данными поверх изображения; ограничение — 30 запросов тайлов в секунду. Временный кеш ограничен 30 днями. Вывод относится к карте адресов заявок: он не является подтверждением условий GPS-мониторинга транспорта, диспетчеризации или маршрутной оптимизации.

## Сравнение

| Вариант | Стоимость карты | Что получим | Ограничение |
|---|---:|---|---|
| **Яндекс Tiles + OpenLayers** | **0 ₽**, до 30 запросов тайлов/с | Яндекс-подложка, свои метки, карточки и управление; без Leaflet | Не включает поиск адресов и весь интерфейс нативного JS API |
| **2ГИС MapGL + Map Tiles API** | **От 8 000 ₽/месяц** за 100 000 тайлов | Собственная интерактивная карта 2ГИС, без Leaflet | Оплата по тайлам; поиск адресов оплачивается отдельно |
| **Яндекс JavaScript API** | **195 000 ₽/год** либо **41 600 ₽/30 дней** | Нативная библиотека Яндекса | Для закрытой CRM нужна коммерческая лицензия; бесплатный trial максимум 7 суток |

Источники цен: [2ГИС](https://docs.2gis.com/platform-manager/subscription/pricing), [Яндекс JS API](https://yandex.ru/dev/tariffs/doc/ru/jsapi/prices/). Тариф Яндекса без рекламы за 2 000 ₽/месяц предназначен только для открытых проектов и не заменяет коммерческую лицензию закрытой CRM. Бесплатная библиотека 2ГИС MapGL не означает бесплатные данные карты; постоянное бесплатное коммерческое использование не предусмотрено, есть месячное демо. [Правила 2ГИС](https://law.2gis.ru/maps-pay).

Более дешёвый 2ГИС RasterJS использует Leaflet ([репозиторий 2ГИС](https://github.com/2gis/mapsapi)), поэтому не выбран основной альтернативой. NextGIS также не выбран: типовая подложка основана на OSM, а платформа добавляет отдельную инфраструктуру. [NextGIS GeoServices](https://nextgis.ru/nextgis-geoservices/).

## Как сделать бесплатный вариант

1. Получить доступ к отдельному пакету **Tiles API** в имеющемся кабинете. Существующее подключение JS API не доказывает доступ к Tiles. Ключ не выводить в чат/Git/логи; активация по документации занимает до 15 минут. [Быстрый старт](https://yandex.ru/maps-api/docs/tiles-api/quickstart.html).
2. Один модуль OpenLayers для карты заявок и выбора точки в заявке/справочнике. Только официальный источник Яндекса, без скрытого перехода на OSM. OpenLayers — проект OSGeo с международным сообществом, а не Leaflet. [OpenLayers](https://www.osgeo.org/projects/openlayers/).
3. Явно использовать `projection=web_mercator`, согласованный с OpenLayers EPSG:3857. По умолчанию у API другая проекция; её смешение с библиотекой сместит дома относительно меток. Стиль `future_map` документирован, Retina поддерживается `scale=2`. [Формат запроса](https://yandex.ru/maps-api/docs/tiles-api/request.html).
4. Сохранить нынешние карточки с компанией/литрами/адресом и мобильное нажатие; общие координаты объединять. Логотип, авторство и переход в Яндекс.Карты оставлять видимыми. [Требования к отображению](https://yandex.ru/maps-api/docs/tiles-api/index.html).
5. Ограничивать общий поток запросов с запасом к 30 rps; при серверной выдаче использовать защищённый маршрут, корректный Referer, кратковременный кеш и объединение одинаковых запросов. Прокси и его точные настройки ещё не реализованы. [Ограничения доступа](https://yandex.ru/maps-api/docs/tiles-api/limit.html).
6. «Показать всё» каждый раз строит обзор по реальным точкам. Для единственной/общей точки — центр и ограниченный масштаб; для нескольких — охват с отступами. Обновление данных сохраняет ручной вид карты.

Точная скорость, вид нового стиля на Бианки/Силикате и работа Tiles с данным аккаунтом пока не проверены. Это кандидат, а не уже подключённая production-карта.

## Поиск адресов — отдельная часть

Tiles API показывает карту, но не определяет координаты адреса. Собственные ручные точки и исторические снимки сохраняются. Сейчас автоматический поиск использует Nominatim/OSM: замена картинки на Яндекс сама по себе этот источник не меняет.

Если требуется полностью исключить новые обращения к OSM, для неизвестных адресов нужен ручной выбор точки либо отдельно выбранный геокодер. Нельзя молча отключать работающий поиск или автоматически подключать платный Яндекс-геокодер. Постоянное хранение ответов Яндекса требует отдельного права. [Условия геокодера](https://yandex.ru/dev/tariffs/doc/ru/geocoder/terms/).

Сам OSM — международный проект с британским фондом; Leaflet — отдельная библиотека, автор которой работал из Киева. Это разные компоненты. Предлагаемая замена убирает Leaflet и OSM-тайлы, но не делает утверждений о происхождении каждого участника всех сторонних зависимостей. [OSMF](https://osmfoundation.org/wiki/About), [публикация автора Leaflet](https://leafletjs.com/2022/04/18/leaflet-1.8.0.html).
