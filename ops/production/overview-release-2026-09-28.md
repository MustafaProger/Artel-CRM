## Что изменилось

Отдельная страница взаиморасчётов перенесена в «Обзор». Рядом с фирмой показан
общий баланс: долг красным с минусом, аванс зелёным с плюсом. Добавлены месячные
диаграммы, список долгов и карточка фирмы с поступлениями и отгрузками.
Старый адрес `#settlements` открывает `#overview`.

Директор и администратор видят общие итоги. Менеджер получает только свою
область клиентов, отгрузок и поступлений; вложенные распределения и суммы
также ограничены сервером. Назначенные фирмы без операций показываются
с нулевым балансом. Переназначение клиента закрывает прежний доступ, а создание
фиктивной отгрузки не позволяет присвоить чужого или неназначенного клиента.
Для общего ИНН показывается только часть поступлений, зачтённая в собственные
отгрузки; общий свободный аванс остаётся доступен руководителю.

Сохранены общий баланс клиента и существующая очередь распределения оплат.
**Распределение списаний и долга по нашим организациям и банковским счетам
не реализовано:** требуется отдельное согласование. [Открытые вопросы и
напоминание для следующей задачи](../../docs/next-task-bank-balances.md).

## Откат кода

Сохранить текущий `/opt/artel-crm/.env`, затем заменить в нём только значение
`ARTEL_IMAGE` на `artel-crm:20260928-bank-sync` и выполнить:

```sh
docker compose --project-directory /opt/artel-crm config --quiet
docker compose --project-directory /opt/artel-crm up -d --no-build --pull never crm
```

Проверить `healthy`, `/healthz` и публичные assets предыдущей сборки.
Актуальные данные, банковские токены, `runtime.env` и исходный снимок оставить
на месте; восстановление старого хранилища для отката кода не требуется.
Не запускать второй runtime на общем томе, не удалять `.runtime.lock`,
не пересоздавать соседние службы и не перезапускать Caddy.
